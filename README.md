 # E-commerce Sales Analysis

## Project Overview
This project explores Brazilian e-commerce data from the Olist dataset to understand sales performance, monthly revenue trends, and product category performance.

The goal is to practice data analysis using Python and transform raw transactional data into meaningful business insights.

## Dataset

- **Source:** [Brazilian E-commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
- **Platform:** Kaggle
- **Data type:** E-commerce orders, order items, and product categories

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Analysis

- Inspected dataset structure and missing values.
- Analyzed monthly order volume and product revenue.
- Identified the top 10 product categories by sales value.
- Calculated the revenue contribution of leading product categories.
- Visualized sales trends and category performance.

## Project Outputs
Charts generated during the analysis are saved in the `outputs/` directory.

## Key Findings
The analysis examines monthly revenue trends and differences in product category performance.

Specific findings and business recommendations will be documented after validating the final results.

- Data aggregation using Pandas

- Data visualization
- Business-oriented interpretation of data
